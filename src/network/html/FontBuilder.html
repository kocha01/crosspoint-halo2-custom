🔤 PokiInk .cpfont Builder

Convert TTF/OTF fonts into PokiInk's .cpfont format in your browser. All processing is local — your font files never leave this page.

1. Pick a font file

📂 Drop .ttf or .otf here, or click to pick

No font loaded

2. Choose sizes (max 5)

Exactly five slots. PokiInk picks the closest match to the user's reader font size, so include the ones you'll actually read at (typical: 14, 16, 18, 20, 22). Leave a slot blank to skip it. Valid range 6–80 pt.

3. Character coverage

What goes into the font. The default "Thai + English" pulls Latin, Latin-1, Thai block, and general punctuation in a single click — no decisions needed.

Advanced ranges (when "Custom" is selected)

Tick the blocks to include, or add comma-separated start-end hex pairs.

4. Family name

Becomes the folder name on the SD card (/fonts/<Family>/). Letters / digits / dashes only.

5. Build & upload

Pipeline mirrors lib/EpdFont/scripts/fontconvert_sdcard.py. For full feature parity (bold/italic, kerning classes, ligatures), run the Python script instead. This page handles the common case of building a single-style family quickly.
